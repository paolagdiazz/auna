# Aúna · Brand kit / Kit de marca

## English

| Folder | Contents |
| --- | --- |
| `01_logotipo` | Horizontal logo (colour and on green), vertical logo, sunflower symbol, wordmark and app icons. |
| `02_tarjetas-qr` | ID-card size QR cards (85.6 × 54 mm), green and cream, with a demo QR or as a blank template. |
| `03_colores` | Colour palette as PNG, SVG and PDF, plus the codes as CSS, JSON and TXT. |
| `04_tipografia` | Type sheet, the Nunito fonts (TTF, SIL Open Font License) and CSS for the web. |

**Formats**
- **SVG**: vector, scales without losing quality (web, Figma, Illustrator).
- **PDF**: vector, for printing. Cards print at real size.
- **PNG**: high resolution with a transparent background (logos around 4200 px, cards at 600 dpi).

Text in the logos is converted to outlines, so it looks the same without the font installed. The demo QR only contains the text «Aúna · Pasaporte de Marco (demo)». For a real card, use the link to the child's passport.

## Español

| Carpeta | Contenido |
| --- | --- |
| `01_logotipo` | Logo horizontal (color y sobre verde), vertical, símbolo del girasol, wordmark e iconos de app. |
| `02_tarjetas-qr` | Tarjetas tamaño carné (85,6 × 54 mm), verde y crema, con QR de demo o como plantilla sin QR. |
| `03_colores` | Paleta en PNG, SVG y PDF, y los códigos en CSS, JSON y TXT. |
| `04_tipografia` | Ficha tipográfica, fuentes Nunito (TTF, licencia SIL OFL) y CSS para la web. |

**Formatos**
- **SVG**: vectorial, escala sin perder calidad (web, Figma, Illustrator).
- **PDF**: vectorial, para imprimir. Las tarjetas salen a tamaño real.
- **PNG**: alta resolución con fondo transparente (logos de unos 4200 px, tarjetas a 600 ppp).

Los textos de los logos están convertidos en trazos: se ven igual sin tener la fuente instalada. El QR de demo solo contiene el texto «Aúna · Pasaporte de Marco (demo)». Para una tarjeta real hay que usar el enlace al pasaporte del niño.
